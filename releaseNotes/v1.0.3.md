# OpenEtradeMcp v1.0.3

Release Date: 2026-10-03

## What's New

### Portfolio Tax-Lot Support

Added the missing E*TRADE per-position tax-lot endpoint to the OpenAPI definition as `getPositionLots`.

This resolves a gap where the main portfolio response does not include individual lot data, even when `lotsRequired=true`. E*TRADE exposes the actual tax-lot information on a separate endpoint:

- `GET /accounts/{accountIdKey}/portfolio/{positionId}`

The new operation reuses the existing `PortfolioResponse` / `PositionLot` schemas and exposes the missing MCP tool needed to retrieve lot-level details such as:

- cost basis
- acquisition date
- term code
- remaining quantity
- individual lot pricing

This enables downstream tax analysis and lot-selection workflows that depend on per-position tax-lot data.

### Package Release Quality

Fixed NuGet package README inclusion by correcting the MSBuild path resolution used during packaging, ensuring the package metadata is included correctly in published artifacts.
