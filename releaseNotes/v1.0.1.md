# OpenEtradeMcp v1.0.1

Release Date: 2026-04-13

## What's New

### Safety and Confirmation
- Added opt-in order confirmation via MCP elicitation for dangerous operations (`placeOrder`, `cancelOrder`, `placeChangeOrder`) from commit `b0a89c1`
- Confirmation is off by default (`EnableOrderConfirmation=false`) to preserve existing behavior
- Added token-based fallback confirmation flow for MCP clients without elicitation support
- Added cancel-order enrichment to show real order details before confirmation
- Added account key resolution to human-friendly masked account display in confirmation dialogs

### Dependency Updates
- Upgraded `OpenApiMcpNet` to `1.0.2`
- This includes the enum handling fix for OpenAPI enum parameters that resolves order tool validation failures described in [Issue #6](https://github.com/kerryjiang/OpenEtradeMcp/issues/6)
- Enum values now validate against expected values (for example `BUY`, `SELL`, `MARKET`, `EQ`) instead of invalid type-name values like `Microsoft.OpenApi.Any.OpenApiString`

### Unit Tests
- Added `OpenEtradeMcp.Tests` xUnit test project targeting .NET 10.0
- Tests cover `ETradeConfig` (base URL selection, default confirmation settings), `EtradeOAuthSession` (authentication state), and `EtradeOAuth1AuthenticationHandler` (constructor validation, authorization URL formatting, token-missing guards)

### Bug Fixes
- Fixed `EtradeOAuth1AuthenticationHandler` constructor to eagerly validate `etradeConfig` before passing it to the base class, ensuring a proper `ArgumentNullException` is thrown instead of a `NullReferenceException`
